# دوام — متتبع العادات

تطبيق ويب (PWA) بسيط يشتغل بدون إنترنت. البيانات بتتحفظ على جهازك بس.

## الرفع على GitHub Pages
1. اعمل Repository جديد على GitHub (مثلاً `dawam`).
2. ارفع كل ملفات المجلد ده في الـ root بتاع الـ Repository (index.html و manifest.json و sw.js وملفات الصور).
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Folder: / (root) ← Save.
4. بعد دقيقة افتح الرابط https://USERNAME.github.io/dawam/ من الموبايل.

## التثبيت كتطبيق
- أندرويد (كروم): زرار «تثبيت التطبيق» في الإعدادات أو من قايمة المتصفح ← Install app.
- آيفون (سفاري): مشاركة ← إضافة إلى الشاشة الرئيسية.
