# دوام — لوحة التحكم الشخصية

تطبيق ويب (PWA) بسيط يشتغل بدون إنترنت: مهام يومية، تتبع عادات، وصندوق أفكار. البيانات بتتحفظ على جهازك بس، فاعمل **تصدير نسخة احتياطية** من تبويب «نسخ احتياطي» بشكل دوري.

## الملفات المطلوبة (كلها في نفس المجلد)
`index.html` · `manifest.json` · `sw.js` · `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png`

## الرفع على GitHub Pages
1. اعمل Repository جديد على GitHub (مثلاً `dawam`).
2. ارفع كل الملفات فوق في الـ root.
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Folder: / (root) ← Save.
4. بعد دقيقة افتح `https://USERNAME.github.io/dawam/` من الموبايل.

## التثبيت كتطبيق
- أندرويد (كروم): زرار «📲 تثبيت» في أعلى الصفحة، أو قايمة المتصفح ← Install app.
- آيفون (سفاري): مشاركة ← إضافة إلى الشاشة الرئيسية.

## ملاحظات
- لما تعدّل أي ملف، غيّر `CACHE_NAME` في `sw.js` (مثلاً `dawam-v5`).
- خط Cairo بيتحمّل من Google Fonts أول مرة أونلاين وبعدها بيتخزّن؛ لو مش متاح التطبيق بيستخدم خط النظام.
